# 성경 읽기 중계 서버

공개 화면은 `../bible/`, 서버 정본은 이 디렉터리다. Python 3.10 이상 표준 라이브러리만 사용한다. 사용자 로그인/OAuth는 사용하지 않는다.

## 비밀 설정

App Key는 `~/.config/finance-fixer/youversion-app-key`에 한 줄로 보관하고 파일 권한을 0600으로 둔다. 저장소에 추가하지 않는다. 서버는 `YVP_KEY_FILE`로 다른 경로를 받을 수 있다.

개발 실행: `python3 bible-service/server.py --development --port 8795` → `http://127.0.0.1:8795/bible/`.

운영 실행은 `bible-api.service`를 사용한다. `127.0.0.1:8760`만 열고 `bible-api.finance-fixer.net`의 cloudflared가 직접 연결한다. 중간 프록시를 추가하면 IP 신뢰 처리를 다시 검토한다. 공개 정적 파일은 GitHub Pages가 제공한다.

## 제공 범위와 제한

- `/chapter?book=MRK&chapter=1`: NIV 2011 한 장과 현재 저작권 문구. 책·장 허용목록, 원문 각주 포함. 메타·본문 어느 쪽이 실패해도 NIV를 반환하지 않는다.
- `/fonts.css`: 공식 Fonts API의 CSS. 글꼴 파일은 직접 호스팅하지 않는다. CSS만 서버 메모리에 15분 보관한다.
- `/healthz`: 서비스 상태. 본문·키는 포함하지 않는다.
- 본문 응답은 `no-store`. 서버 디스크/로그에 NIV 본문을 저장하지 않는다. HTML은 브라우저에서 검증한 뒤 렌더링한다.
- 허용 Origin은 finance-fixer.net와 www.finance-fixer.net. Origin 검사는 인증이나 완전한 복제 방지가 아니다.
- IP당 분당30개 요청·상류12회(통상 본문6장), 시간당 상류36회, 하루 상류240회. 전역 상류 분당60회/시간당180회/하루10000회 상한. 2026-11-20 운영 전환 후 관리 화면의 공급자 한도는 시간당200회로 표시되어, 여유를 둔 자체 시간당 상한을 적용했다. IPv6는 /48 단위로 묶는다. 사용자의 IP 원문 대신 메모리 해시로 제한을 계산하며 기록 파일을 만들지 않는다. 일일 상태는 최대4096개, 만료 시 삭제하고 가득 차면 가장 오래된 항목을 교체한다. 캐시된 글꼴 요청은 일일 상태를 만들지 않는다.
- 공급자 제한은 별도로 적용된다. 429일 때 Retry-After의 대기시간 동안 상류 재요청을 중단한다. 사용자에게는 정제된 오류코드와 대기 초만 반환하며 상류 오류 본문·키를 전송하지 않는다.
- `NIV_ENABLED=0`이면 NIV를 즉시 중지한다. 한글 정적 본문은 계속 사용 가능하다. systemd 환경 설정을 바꾸고 재시작한다.

## 검증과 운영

`python3 -m unittest discover -s bible-service -v`는 외부 호출 없이 경로·본문/출처 검증·키 누출·요청 상한·리다이렉트·HEAD 등을 검사한다.

공개 전: 서비스 로컬 확인 → Cloudflare DNS/ingress 백업·추가 → HTTPS/CORS/no-store 확인 → GitHub Pages 공개파일 배포 → 실제 브라우저 확인. 기존 포트·호스트를 덮어쓰지 않는다. 롤백은 홈페이지의 성경 관련 커밋만 되돌리고 신규 ingress/DNS만 제거한 뒤 서비스를 중지한다. 다른 사이트의 변경을 함께 되돌리지 않는다.

개역한글 출처·커밋·해시·표본 대조 범위는 `../bible/krv-source.json`에 기록했다. 전체 공식 본문을 대조한 것은 아니다. 오류를 정정할 때는 대한성서공회 기준 본문과의 비교 근거를 남긴다.

기존 첫 학습 단원은 `lesson.html`로 유지한다. 자체 영어 예문 듣기와 외부 NIV 낭독 링크를 제공하며, 새 NIV 합성음원의 권한이 확보됐다는 뜻이 아니다. 장별 전체 해설도 아직 작성되지 않았다.
