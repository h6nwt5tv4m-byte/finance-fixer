Privacy Policy

Effective date: October 7, 2026 · Applies to: 재무해결사 Uploader (Google Cloud project ff-youtube-upload)

What this application is

재무해결사 Uploader is an internal tool operated by 재무해결사 (Finance Fixer), an accounting office in Korea. It is used only by our staff to upload videos that we produce to our own YouTube channel. It is not offered to the public and does not access any other person's YouTube account.

YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information we access, use and store

  • OAuth credentials: when our channel owner signs in, Google issues an access token and refresh token. These are stored only on our office computer, in a file readable by our account, and are used only to call the YouTube Data API on behalf of our own channel.
  • Video files and metadata: the video files, titles, descriptions, tags, thumbnails and publishing schedule that we prepare are sent to YouTube to create uploads on our channel.
  • Upload results: the video ID and upload status returned by the API are kept in a local log so we can confirm what was published.

We do not collect, store or process information about YouTube viewers or any other YouTube users, and we do not use cookies or analytics in this application.

Sharing

We do not sell, share or disclose any data obtained through YouTube API Services to third parties. Data is sent only to Google/YouTube as required to perform the upload.

Retention and deletion

Credentials are kept until access is revoked or the tool is retired, after which the local credential file is deleted. Upload logs contain only our own video IDs and titles. Access can be revoked at any time from the Google security settings page, which immediately stops the application from accessing the channel.

YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관이 적용되며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

접근·이용·보관하는 정보

  • OAuth 인증정보: 채널 소유자가 로그인하면 발급되는 액세스·갱신 토큰입니다. 사무소 컴퓨터에만 저장하고, 우리 채널에 대한 YouTube Data API 호출에만 씁니다.
  • 영상 파일과 메타데이터: 우리가 준비한 영상 파일, 제목, 설명, 태그, 썸네일, 공개 일정을 YouTube로 전송합니다.
  • 업로드 결과: API가 돌려준 영상 ID와 상태를 업로드 확인용으로 로컬 기록에 남깁니다.

시청자나 다른 YouTube 사용자의 정보는 수집·저장·처리하지 않으며, 쿠키나 분석 도구를 쓰지 않습니다.

제3자 제공

YouTube API 서비스로 얻은 정보를 판매하거나 제3자에게 제공하지 않습니다. 업로드에 필요한 범위에서 Google/YouTube로만 전송합니다.
