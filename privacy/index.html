Privacy Policy

Effective date: October 7, 2026 · Applies to: 재무해결사 Uploader (Google Cloud project ff-youtube-upload)

What this application is

재무해결사 Uploader is an internal tool operated by 재무해결사 (Finance Fixer), an accounting office in Korea. It is used only by our staff to upload videos that we produce to our own YouTube channel. It is not offered to the public and does not access any other person's YouTube account.

YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information we access, use and store

  • OAuth credentials: when our channel owner signs in, Google issues an access token and refresh token. These are stored only on our office computer, in a file readable by our account, and are used only to call the YouTube Data API on behalf of our own channel.
  • Video files and metadata: the video files, titles, descriptions, tags, thumbnails and publishing schedule that we prepare are sent to YouTube to create uploads on our channel.
  • Upload results: the video ID and upload status returned by the API are kept in a local log so we can confirm what was published.

We do not collect, store or process information about YouTube viewers or any other YouTube users, and we do not use cookies or analytics in this application.

Sharing

We do not sell, share or disclose any data obtained through YouTube API Services to third parties. Data is sent only to Google/YouTube as required to perform the upload.

Retention and deletion

Credentials are kept until access is revoked or the tool is retired, after which the local credential file is deleted. Upload logs contain only our own video IDs and titles. Access can be revoked at any time from the Google security settings page, which immediately stops the application from accessing the channel.

성경으로 영어 공부

시행일: 2026년 11월 24일 · 적용 대상: finance-fixer.net/bible/.

회원가입 없이 이용하며, 최근 읽은 책·장·영어 번역과 첫 단원 읽음 표시는 사용 중인 브라우저에 저장합니다. 브라우저의 사이트 데이터를 삭제하면 지워집니다. 학습 화면을 열면 사무소 서버가 날짜별 전체 조회수를 셉니다. 이 통계에는 계정, IP 주소, 읽은 책·장·절을 기록하지 않습니다.

기존 NIV 전용 링크를 열면 책·장을 사무소 중계 서버에서 YouVersion API로 요청합니다. 중계 서버는 성경 본문이나 개인별 열람 이력을 별도 파일로 저장하지 않습니다. 과도한 요청을 제한하기 위한 IP 해시와 호출 횟수는 서버 메모리에서만 관리하고 최대 24시간 후 만료됩니다. 호스팅·통신 제공자의 접속기록은 각 서비스의 방침에 따릅니다.

영어 학습 단어와 예문은 채터박스로 미리 만든 음원 파일을 이 사이트에서 재생합니다. BSB 영어 본문·단어 강조 자료와 마가복음 1장 1–8절 연습 음원은 이 사이트에서 제공합니다. 장 전체의 낭독을 재생하면 브라우저가 OpenBible.com에서 Barry Hays의 음원을 불러오며 접속 IP 주소와 브라우저 정보가 전달됩니다. NIV 공식 낭독을 펼치면 재생을 누르기 전에도 브라우저가 선택한 책과 장을 YouVersion(Bible.com)에 직접 요청할 수 있습니다. 이때 IP 주소와 브라우저 정보가 제공처에 전달되며, 쿠키 등에는 YouVersion 개인정보처리방침이 적용됩니다. 음원은 제공처에서 스트리밍합니다.

NIV 마가복음 1장에는 LUMO의 공식 YouTube 영상이 표시됩니다. 이 장을 열면 재생 전에도 YouTube에 연결되어 방문자의 IP 주소, 브라우저 정보와 사이트 출처가 전달될 수 있습니다. 영상에는 YouTube 서비스 약관이 적용되며, 재생과 관련 쿠키에는 Google 개인정보처리방침이 적용됩니다.

글꼴을 표시할 때 YouVersion CDN과 Google Fonts에 연결됩니다. 외부 성경·낭독·해설 링크를 열면 해당 제공자의 서비스와 개인정보처리방침이 적용됩니다. 문의: info@finance-fixer.net.

홈페이지 상담 신청

재무해결사는 신청자의 동의를 받아 회신 이메일과 상담 주제, 선택해서 적은 상담 내용을 수집합니다. 상담 접수·회신과 진행 상태 관리에 사용하고 사무소 운영자가 열람합니다. 상담 신청은 로그인 없이 이용할 수 있습니다. 블로그 안내 링크로 들어와 신청하면(같은 브라우저 탭 안에서는 홈페이지를 거쳐도 표시가 이어집니다) 신청 내용과 연결하지 않고 유입 경로별 주간 신청 건수만 셉니다.

접수일부터 90일간 보관하고 기간이 지난 신청은 매일 삭제합니다. 접근이 제한된 일별 복구 사본은 최대 7일간 순환 보관합니다. 임시 복구 파일은 작업 후 정리하며, 삭제한 상담이 다시 표시되지 않도록 임의 번호와 삭제 시각만 90일간 보관합니다. 동의를 거부할 수 있으며, 거부하면 온라인 신청을 접수할 수 없습니다. 열람·정정·삭제 요청은 info@finance-fixer.net으로 보내 주세요.

홈페이지 계정과 자유게시판

공개글은 누구나 읽을 수 있습니다. 비밀글의 제목·본문·댓글은 작성자와 게시판 운영자가 열람할 수 있습니다. 글에는 고객 자료나 연락처를 올리지 마세요.

홈페이지와 공개 도구, 자유게시판에서 같은 이메일 인증 계정을 사용합니다. 로그인하면 공통 메뉴에 계정 별명이 표시됩니다. 인증 메일은 사무소 발신 계정의 메일 서비스(Google)를 통해 보냅니다. 게시판은 이메일을 비밀키로 변환한 식별자를 사용하며, 화면에는 별명을 표시합니다. 요청을 확인하기 위한 인증번호는 10분간 유효하고, 로그인 쿠키는 최대 7일간 이용할 수 있습니다. 로그아웃하면 해당 로그인을 종료합니다.

북웜에서는 로그인한 계정별로 책마다 최근 읽은 장·장면과 낭독 시간을 저장해 다른 기기에서도 이어 읽게 합니다. 비회원의 읽기 위치와 재생 설정은 사용 중인 브라우저에 저장합니다. 계정의 북마크는 삭제를 요청할 때까지 보관합니다.

글에 사진을 첨부하면 사진을 다시 저장하면서 촬영 위치, 기기 정보 같은 사진 속 부가 정보를 지웁니다. 사진은 글과 같은 공개 범위로 표시되고, 글을 삭제하면 함께 삭제됩니다. 다른 사람의 개인정보·사생활·명예를 침해하는 글과 사진은 당사자가 요청하면 지체 없이 삭제하거나 임시로 가립니다.

도배 방지를 위해 접속망과 계정의 식별자로 최근 24시간의 요청을 제한합니다. 글과 댓글은 게시 중 보관합니다. 본인이 삭제하거나 운영자에게 삭제를 요청할 수 있습니다. 일별 복구 사본은 최근 7일분을 보관합니다. 공개 글 목록과 공개 글을 열면 사무소 서버가 날짜별 전체 조회수를 셉니다. 통계에는 IP 주소, 계정, 글 주소를 기록하지 않습니다. 내 글, 비밀글, 로그인, 상담 화면은 집계에서 제외합니다. 운영·삭제 문의는 hyungjun@finance-fixer.net로 보내 주세요.
